# MD Nojrul Khan — Free Portfolio Website

This is the first static version of the portfolio website.

## Files
- `index.html` — website structure/content
- `style.css` — responsive design
- `script.js` — mobile menu + scroll animations
- `assets/profile-photo.png` — supplied profile photo
- `assets/resume-reference.png` — supplied CV/resume reference image

## Free publishing
The site can be published free with GitHub Pages.

1. Create a GitHub account.
2. Create a repository named `YOURUSERNAME.github.io`.
3. Upload all files and the `assets` folder.
4. In repository Settings → Pages, enable deployment from the main branch.
5. Your site will be available at `https://YOURUSERNAME.github.io/`.

## Important about photo/text uploading
This first version is a static website, so visitors cannot upload content and you cannot publish new posts from a dashboard yet.

The next version can add a free/low-cost CMS or a simple admin workflow for:
- adding blog posts
- uploading photos
- adding certificates
- adding projects/portfolio items

Do not put passwords, private keys, or other secrets into this static repository.
